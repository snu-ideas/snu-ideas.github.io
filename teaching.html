조선공학특론 Advanced Topics in Naval Architecture

조선해양 데이터 분석 및 활용 — Ship and Ocean Data Analysis and Applications

Course objectives

This course develops the practical ability to process and analyze data in one's own research field through programming. It revisits the fundamentals of programming and covers the Python libraries NumPy and pandas, applying them to data processing in naval architecture and ocean engineering — including AIS data analysis and a hands-on introduction to vibe coding.

  • Programming
  • Python
  • NumPy
  • pandas
  • Data analysis
  • AIS data
